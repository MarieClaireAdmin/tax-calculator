式典資材管理

安裝入口會依你的裝置，自動顯示正確步驟。

iPhone / iPad

加入主畫面

  1. 下載安裝描述檔下載式典資材管理
  2. 開啟 設定，點「已下載描述檔」。如果沒看到，前往「一般 → VPN 與裝置管理」。
  3. 點「安裝」完成。主畫面會出現「式典資材管理」。

此描述檔只建立一個主畫面 Web Clip，不會加入 VPN、帳號、憑證或裝置管理。

Android

加入主畫面

  1. 先安裝 Native Alpha前往 Google Play 安裝

    已經安裝過的話，直接做下一步。

  2. 下載式典資材管理設定下載安裝設定
  3. 開啟 Native Alpha → Settings → Import，選剛下載的「式典資材管理設定」。
  4. 看到建立主畫面捷徑的提示時按 OK / Add。名稱與正式圖示會自動帶入，不需要自己找圖片。

第一次使用拍照功能時，Android 仍會要求你本人允許相機／照片權限。

電腦

直接使用

電腦不需要安裝手機元件，直接開啟正式系統即可。

開啟式典資材管理

正在判斷裝置

如果畫面沒有自動切換，請重新整理一次。
